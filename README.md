# Elden Ring Progress Tracker

Personal single-file tracker: recommended levels, area order, quest warnings, item locations on a map, checklist + written guide.

Live: https://rawallon.github.io/elden-ring-tracker/

Open `index.html` locally or via any static server. Progress is stored in browser localStorage.

## Credits
Route order, levels and notes are based on the [Fextralife Game Progress Route](https://eldenring.wiki.fextralife.com/Game_Progress_Route), summarised in own words. Pin coordinates derived from the public jw-ofs/elden-ring-map data. Unofficial fan project; Elden Ring is property of FromSoftware / Bandai Namco.
